# 빛길 (Bitgil)

개발자: **KIM YEONGDO**

교회 예배당 조명을 Windows 노트북에서 직접 제어하는 3D 조명 제어 프로그램이다. 조명 콘솔 대신 USB-DMX 인터페이스 하나로 조명 36대(DMX 1유니버스)를 다루고, 예배당과 빛줄기를 3D 화면으로 미리 본다.

## 설치 방법

1. [릴리스 페이지](https://github.com/Dubitnarae/bitgil/releases/latest)에서 `bitgil-setup-<버전>.exe`를 받는다.
2. 실행해서 설치한다. 코드 서명이 없어서 Windows가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행]을 누른다.
3. 바탕화면의 **빛길**로 켠다.

- Windows 전용이다.
- 새 버전이 나오면 켤 때 안내가 뜬다. [받아 두고 끌 때 설치]를 고르면 프로그램을 끌 때 설치된다(운영 중에는 설치하지 않는다).
- 쇼 파일(씬·패치·공간)은 `문서\빛길\show.bitgil.json`에 저장되고, 저장할 때마다 백업을 10개까지 남긴다. 업데이트해도 쇼 파일은 바뀌지 않는다.
- 설정은 `%APPDATA%\빛길\settings.json`, 오류 기록은 `%APPDATA%\빛길\error.log`에 있다.

## 주요 기능

- **3D 화면**: 예배당, 조명, 예상 빛줄기를 보여 준다. 화면 품질(낮음·보통·높음·자동)은 상단에서 고른다.
- **미리보기 → [적용]**: 운영 중 변경은 미리보기에만 반영되고, [적용]을 눌러야 실제 조명으로 페이드된다. [취소]는 되돌린다.
- **즉시 동작**: 블랙아웃(단축키 `B`), 기본 조명(단축키 `H`), 전체 밝기는 누르는 즉시 나간다.
- **조명 조정**: 밝기, 색(RGBW, 색 팔레트), 팬·틸트, 줌, 셔터. [빛 위치 찍기]로 3D 바닥·벽을 눌러 빛을 그 자리로 보낸다.
- **씬과 씬 페이더**: 조정한 상태를 씬으로 저장하고, 씬마다 페이더로 섞는다. 페이더를 바로 내보낼지 미리보기 후 적용할지는 설정에서 고른다.
- **순서 목록**: 씬을 순서와 페이드 시간으로 늘어놓고 [다음]·[이전]으로 진행한다.
- **편집 모드(PIN)**: 정식 씬 저장·삭제, 패치·공간 수정, 조명 찾기, 설정은 4자리 PIN으로 연 편집 모드에서만 된다. 10분 동안 조작이 없으면 운영 모드로 돌아간다.
- **조명 찾기·채널 시험**: 조명을 하나씩 켜서 실제 조명과 3D 위치·DMX 주소를 맞춘다.
- **폰 원격**: 같은 Wi-Fi의 폰 브라우저로 현재 상태를 보고 [다음 씬]·[기본 조명]·[블랙아웃]을 누른다. 설정에서 켜고 QR 코드로 접속한다(6자리 접속 코드). 폰에서 PIN을 넣으면 객석에서 조명 찾기·주소·위치 수정도 할 수 있다.
- **콘솔 백업 불러오기·내보내기**: Mini Pearl 1024 Pro의 `.XHD` 백업에서 씬을 가져오고 다시 내보낸다(효과 장면은 제외).
- **쇼 파일 옮기기**: 설정에서 쇼 파일을 내보내고 가져와 다른 컴퓨터로 옮긴다.

## 장비 연결

```
노트북 ─ USB ─ USB-DMX 인터페이스 ─ DMX 선 ─ (분배기) ─ 조명
```

1. USB-DMX 인터페이스를 노트북에 꽂는다. 콘솔을 쓰던 곳이라면 콘솔에 꽂혀 있던 DMX 선을 인터페이스로 옮겨 꽂는다.
2. 빛길 → 편집 모드 → 설정에서 인터페이스 종류와 포트를 고른다.
   - **Enttec Pro 호환**: Enttec DMX USB Pro, DMXking ultraDMX Micro
   - **Open DMX 호환**: FTDI 칩을 쓰는 제품(Lixada USB-DMX512 등)
   - **uDMX (Anyma 호환)**: COM 포트 없이 'uDMX'로 보이는 제품. 처음 한 번 WinUSB 드라이버 설치 필요 — 설정의 [uDMX 드라이버 설치] 버튼(빛길에 함께 담긴 [Zadig](https://zadig.akeo.ie/), GPL v3, `vendor/zadig/README.md`). USB 허브를 거쳐 꽂아야 안정적(docs/장비-시험-점검표.md 2-1)
3. 상단 [출력 켜기]를 누른다. 켜기 전에는 **출력 대기** 상태라 실제 조명으로 나가지 않는다.

- 선이 빠지면 상단 상태가 빨갛게 바뀌고 2초마다 다시 연결한다.
- 출력이 켜져 있는 동안은 절전·화면 꺼짐을 막는다. 노트북 덮개를 닫는 것은 막지 못한다.
- 처음 연결할 때는 [docs/장비-시험-점검표.md](docs/장비-시험-점검표.md) 순서대로, **예배가 없는 날** 시험한다.
- 장비가 없어도 3D 화면과 채널 모니터로 모든 기능을 써 볼 수 있다.

## 개발

```powershell
npm install
npm run dev    # 개발 모드로 실행
npm test       # 단위 테스트
npm run dist   # 설치 파일 만들기 (dist 폴더)
```

- 구성: Electron + Vite + React + TypeScript, 3D는 Three.js
- 작업 규칙과 안전 규칙: [CLAUDE.md](CLAUDE.md)
- 쇼 파일 형식: [docs/data-format.md](docs/data-format.md)
- 시작 데이터: `data/starter-show.bitgil.json` (조명 36대 패치, 조명 종류 채널표, 공간 치수 추정값, 기존 씬)
