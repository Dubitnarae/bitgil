# 빛길 시작 꾸러미

3D 조명 제어 프로그램 "빛길"을 클로드 코드로 개발할 때 처음에 프로젝트 폴더에 넣는 파일들이다.

| 파일 | 내용 |
| --- | --- |
| `CLAUDE.md` | 클로드 코드가 매번 먼저 읽는 프로젝트 규칙 (안전 규칙, 기술 구성, DMX 전송 형식) |
| `data/starter-show.bitgil.json` | 시작 데이터: 조명 36대 패치·위치, 조명 종류 6가지 채널표, 공간 치수(추정), 기존 장면 13개 |
| `docs/data-format.md` | 쇼 파일 형식 설명 |
| `tools/xhd_parser.py` | 콘솔 USB 백업(.XHD)을 읽는 파이썬 스크립트 (참고용) |

## 쓰는 법

1. `C:\dev\bitgil` 같은 빈 폴더를 만든다.
2. 이 꾸러미 안의 파일과 폴더를 모두 그 폴더에 복사한다 (`CLAUDE.md`가 폴더 바로 안에 있어야 한다).
3. VS Code로 그 폴더를 열고, 터미널에서 `claude`를 실행한 뒤 개발 계획서 1단계의 요청 문장을 붙여 넣는다.

## 실행 방법 (1단계)

```powershell
cd C:\Du_gram\Du_App\bitgil
npm install
npm run dev
```

- `npm test`: 상태 엔진 단위 테스트
- 지금은 **가상 출력**만 있다(실제 조명으로 나가지 않음). 채널 모니터에서 값을 확인한다.
