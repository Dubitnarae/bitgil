# 빛길 실제 장비 시험 점검표

예배가 없는 날에 합니다. 처음 시험할 때는 2시간쯤 잡아 두세요.

## 준비물

- [ ] 노트북(빛길 최신 버전, 충전기)
- [ ] **쇼 파일** `문서\빛길\show.bitgil.json` — 씬 이름·씬·순서 목록·조명 위치가 모두 여기 있음
  - 집 컴퓨터와 같은 OneDrive 계정이 연결된 노트북이면 저절로 같음(출발 전 OneDrive 동기화 완료 확인)
  - 아니면 USB 메모리로 복사해 노트북의 같은 위치(`문서\빛길\`)에 넣기. 빛길을 끈 상태에서 넣고 켠다
  - 시험 중 고친 내용(주소·확인됨 표시 등)은 노트북 쪽 파일에 저장되므로, 끝나면 반대로 집 컴퓨터에 다시 복사
- [ ] Lixada USB-DMX512, USB 절연기 ADuM3160, USB 케이블
- [ ] 콘솔 원본 백업 .XHD (USB 메모리에 따로 한 부)
- [ ] 이 점검표, 필기구, 휴대폰(사진·폰 원격 시험용)

## 1. 시작 전 (콘솔을 원래대로 되돌릴 수 있게)

- [ ] 콘솔 뒤 DMX 케이블 연결을 사진으로 찍어 둔다
- [ ] 콘솔 전원을 끄고 DMX 출력 케이블을 뽑는다 (콘솔과 빛길이 동시에 신호를 보내면 안 됨)
- [ ] 조명실 분배기(R/D PANEL)와 조명 전원이 켜져 있는지 확인한다

## 2. 연결

- [ ] 노트북 → ADuM3160 → Lixada 순서로 꽂는다 (uDMX 제품이면 노트북 → ADuM3160 → **USB 허브** → uDMX. 허브가 없으면 uDMX 가 자꾸 멈추고, 절연기도 인식을 못 함)
- [ ] 콘솔에서 뽑은 DMX 케이블을 Lixada 출력에 꽂는다
- [ ] 장치 관리자 → '포트(COM & LPT)'에 새 COM 번호가 생겼는지 본다 → 번호를 적는다: COM ____
- [ ] 새 포트가 안 생기고 '범용 직렬 버스 컨트롤러'에 **USB Serial Converter**만 있으면: 그것을 두 번 클릭 → [고급] → **VCP 로드(Load VCP)** 체크 → 확인 → USB를 뺐다 다시 꽂는다 (FreeStyler 는 COM 포트 없이도 되지만 빛길은 COM 포트가 있어야 함)
- [ ] 장치 관리자에 COM 포트 대신 **uDMX** 라는 이름(노란 느낌표, '기타 장치')이 보이면 → 아래 '2-1. uDMX 드라이버 설치'를 한다
- [ ] 그래도 안 생기면 Claude에게 알린다(장치 종류를 확인해야 함)

### 2-1. uDMX 드라이버 설치 (처음 한 번만, uDMX 제품일 때)

uDMX 는 COM 포트가 생기지 않는 제품이라, 빛길이 직접 말을 걸 수 있게 'WinUSB' 라는 드라이버를 한 번 넣어 줘야 합니다. 이 일을 해 주는 무료 프로그램이 **Zadig** 입니다. 노트북마다 한 번만 하면 되고, 같은 USB 구멍이 아니어도 다시 할 필요는 없습니다.

- [ ] 인터넷에서 **zadig.akeo.ie** 에 들어가 'Zadig 2.x' 를 내려받는다 (설치 없이 바로 실행되는 파일 하나)
- [ ] uDMX 를 꽂은 채로 Zadig 를 실행한다 ('이 앱이 변경하도록 허용' 창이 뜨면 [예])
- [ ] 위쪽 목록에서 **uDMX** 를 고른다 (목록에 없으면 메뉴 [Options] → [List All Devices] 를 켠다)
  - 고른 뒤 'USB ID' 칸이 **16C0 05DC** 인지 꼭 확인한다. 다른 장치(마우스·키보드·카메라 등)를 고르면 그 장치가 안 될 수 있음
- [ ] 초록 화살표 오른쪽 칸을 **WinUSB** 로 맞춘다
- [ ] [Install Driver] (이미 다른 드라이버가 있으면 [Replace Driver]) → 1~2분 기다려 'successfully' 가 나오면 끝
- [ ] 장치 관리자에서 'Universal Serial Bus devices' 아래에 느낌표 없이 **uDMX** 가 보이면 성공
- [ ] USB 를 뺐다 다시 꽂는다

## 3. 빛길 설정

- [ ] [편집 모드] → [설정] → DMX 출력
- [ ] 인터페이스 종류: **Open DMX 호환 (Lixada …)** — uDMX 제품이면 **uDMX (Anyma 호환 …)**
- [ ] 포트: 위에서 적은 COM 번호 ([다시 찾기]로 목록 새로 고침). uDMX 는 포트를 고르지 않는다(칸이 안 보임)
- [ ] '프로그램을 켜면 바로 장비로 출력'은 **끈 채로** 둔다

## 4. 출력 켜기 (조심해서)

- [ ] 키보드 **B**로 블랙아웃을 먼저 켠다
- [ ] [출력 켜기] → 상단 상태가 '출력 중 · COM__'(uDMX 는 '출력 중 · uDMX')인지 본다 (빨간 '연결 안 됨'이면 아래 '문제가 생기면' 표를 본다)
- [ ] 전체 밝기를 30%쯤으로 낮추고 **B**로 블랙아웃을 푼다

비상시: **B** = 블랙아웃 켜기/끄기, **H** = 기본 조명 (글자 입력 칸 밖에서만 동작)

## 5. 채널 시험 (신호가 실제로 나가는지)

- [ ] 편집 모드 → 오른쪽 '채널 시험' → 흰색 단색 조명(spot_white)의 시작 채널을 넣고 [시험 시작]
- [ ] 그 조명이 켜지는지 본다. [다음 ▶]로 몇 개 더 넘겨 본다
- [ ] 아래 [채널 모니터 열기]로 그 채널만 켜져 있는지 같이 본다
- [ ] 깜빡이거나 불안정하면 적어 둔다 (Open DMX는 컴퓨터가 신호 시간을 맞추는 방식이라 생길 수 있음)
- [ ] [시험 끝]

## 6. 조명 찾기 (36대를 하나씩)

- [ ] 오른쪽 '조명 찾기' → [조명 찾기 시작]
- [ ] 켜진 실물이 3D 화면에서 켜진 조명과 같은 자리인지 본다
  - 같으면 '확인됨' 체크
  - 다르면 주소·위치·방향을 고치거나 '자리 바꾸기'
- [ ] [다음 미확인 ▶]으로 끝까지 → 확인됨 36 / 36
- [ ] 무빙 조명(1-1, 1-2 등): '빛 위치 찍기'로 바닥 한 곳을 찍고 [적용] → 실물이 같은 곳을 비추는지 본다. 어긋난 정도를 적어 둔다

## 7. 씬·순서 목록

- [ ] 씬 페이더를 하나씩 올려 3D 화면과 실물 색·밝기를 비교한다
- [ ] 순서 목록 [다음] → [적용]으로 페이드가 부드러운지 본다
- [ ] (선택) 설정에서 폰 원격을 켜고 폰으로 [다음 씬]·[기본 조명]·[블랙아웃]을 눌러 본다

## 8. 끝내기 (원래대로)

- [ ] 빛길 [출력 끄기(대기)]
- [ ] Lixada에서 DMX 케이블을 빼고 콘솔에 다시 꽂는다 (1번에서 찍은 사진대로)
- [ ] 콘솔을 켜고 아무 장면이나 올려 조명이 정상으로 켜지는지 확인한다

## 문제가 생기면

| 증상 | 먼저 해 볼 것 |
|---|---|
| 상태가 빨간 '연결 안 됨' | 포트 번호 확인 → [다시 찾기]. USB를 뺐다 꽂기 |
| 'uDMX 가 멈췄습니다' | 장치가 굳은 것. USB 를 뺐다 꽂으면 2초 안에 다시 이어짐. 저가 uDMX 를 노트북에 바로 꽂았을 때 수십 초~1분마다 생겼고, **USB 허브를 사이에 끼우니 3분 넘게 한 번도 안 생김** → uDMX 는 항상 허브를 거쳐 꽂기 |
| 절연기(ADuM3160)를 거치면 '알 수 없는 USB 장치' | uDMX 는 느린 USB(Low Speed)라 Full Speed 로 고정된 절연기와 안 맞음 → 노트북 → 절연기 → **USB 허브** → uDMX |
| uDMX 인데 'uDMX 장치를 찾지 못했습니다' | 2-1 의 Zadig 드라이버 설치를 했는지, 장치 관리자에 느낌표가 없는지 확인 → USB 뺐다 꽂기 |
| '출력 중'인데 조명이 전혀 안 켜짐 | 블랙아웃·전체 밝기 확인 → 인터페이스 종류를 다른 쪽(Enttec Pro)으로 바꿔 보기 → DMX 케이블·분배기 전원 확인 |
| 조명이 깜빡이거나 떨림 | 화면 품질을 '낮음'으로, 다른 프로그램 끄기. 계속되면 적어 두고 Claude에게 알리기 |
| 조명이 엉뚱하게 움직임 | **B**(블랙아웃) → 조명 찾기에서 주소 확인 |
| 노트북이 이상하게 꺼지거나 USB가 자꾸 끊김 | 바로 출력 끄기, USB 뽑기. 절연기를 빼고 다시 시험하지 말 것 |
